# YojaTV

Plugin comunitario para Kino enfocado en recopilar películas, series y anime disponibles en español y latino a través de fuentes públicas que no requieran registro obligatorio.

El proyecto busca ofrecer una integración sencilla con Kino, aprovechando su reproductor interno y el sistema de plugins para facilitar la reproducción y, cuando sea compatible, la descarga de contenido para uso offline.

## Características

* Catálogo de películas, series y anime.
* Contenido con audio en español y latino cuando está disponible.
* Soporte para subtítulos.
* Compatibilidad con las funciones de reproducción de Kino.
* Soporte para descargas offline cuando la fuente y Kino lo permiten.
* Integración con QuickJS.
* Plugin firmado por sus autores para facilitar actualizaciones seguras.

## Instalación

### Android / iOS

1. Abre el menú lateral de Kino.
2. Entra en `Plugins`.
3. Pulsa el botón `+`.
4. Introduce el repositorio:

```text
RY456/YojaTV-For-KinoTV
```

5. Pulsa `Agregar`.
6. Selecciona `Instalar`.

### Android TV / Google TV

1. Abre `Ajustes`.
2. Entra en `Plugins`.
3. Selecciona `Agregar`.
4. Introduce:

```text
RY456/YojaTV-For-KinoTV
```

5. Confirma el repositorio.
6. Selecciona `Instalar`.

## Estado del proyecto

El plugin se encuentra actualmente en desarrollo activo.

Las fuentes incluidas están siendo revisadas y probadas para comprobar su compatibilidad con Kino. Este proceso incluye la verificación de endpoints, la detección de fuentes que requieren autenticación, la compatibilidad de los reproductores y la estabilidad de los enlaces de reproducción.

Algunas fuentes pueden dejar de funcionar, cambiar sus endpoints o requerir ajustes sin previo aviso. Por esta razón, el catálogo y la disponibilidad del contenido pueden variar con el tiempo.

## Compatibilidad

La compatibilidad de cada contenido depende de la fuente utilizada, el reproductor disponible y las características que soporte Kino.

El proyecto no aloja directamente las películas, series o anime. El plugin actúa como una capa de integración entre Kino y las fuentes compatibles.
